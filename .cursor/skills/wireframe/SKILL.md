# Wireframe

Load `.cursor/skills/anti-slop/SKILL.md` first. Do not call image specialists on a wireframe pass. Grayscale is not an excuse for a three-card template — structure should already be asymmetric or editorial if the hi-fi will be.

Grayscale only. Structure is the deliverable.

## Build

1. Page `01 Wireframes`.
2. Sitemap from extracted nav + the brief. Typical set: Home, About, Offer, Proof, Contact.
3. For each key page: desktop 1440 and mobile 390, aligned as siblings.
4. Use 8px spacing. Neutral fills `#111`, `#666`, `#DDD`, `#F4F4F4` only.
5. Real labels in the client language. Mark missing copy with `[need: …]`, never lorem.
6. Annotate the primary conversion on each page.
7. Auto-layout every section. Low-fi rectangles for images, labelled (product / people / map).

## Stop

Do not add brand color, shadows, or custom illustration. Hand off to Website Designer.
